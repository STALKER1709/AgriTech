# Crédits photographiques

Les photographies du jeu de démonstration viennent de dépôts d'images libres,
trouvées via [Openverse](https://openverse.org). Elles ont été **téléchargées,
recadrées et enregistrées dans le dépôt** : l'application n'appelle aucun
service distant pour les afficher, et fonctionne donc toujours hors ligne.

Deux familles de licences sont représentées :

| Licence | Obligation |
|---|---|
| **CC0 1.0** et **PDM 1.0** (domaine public) | aucune |
| **CC BY 2.0** | citer l'auteur, la licence et la source |

Les mentions ci-dessous couvrent cette obligation. Elles sont également
affichées dans l'application, sur `/credits-photos`, accessible depuis le pied
de page.

`credits.json`, à côté de ce fichier, contient les mêmes données sous une forme
lisible par la page de crédits.
